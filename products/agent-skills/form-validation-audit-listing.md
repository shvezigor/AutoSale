## Summary

Find confusing form errors, lost input and unsafe server feedback. Get evidence-linked fixes and a practical validation/recovery acceptance plan.

## Description

Help your agent audit the states users actually encounter: invalid submit, field correction, async responses, server failure and successful save. Check feedback, programmatic error associations, keyboard recovery, safe retained values and downstream persistence. Preserve working native validation and existing form patterns instead of requiring a wholesale rewrite.

Includes an audit-report template, acceptance matrix, audit-method reference and fictional before/after example. Findings distinguish confirmed defects from risks and unverified runtime behavior. Actual browser and screen-reader verification require compatible host tools and an authorized test environment. This is a focused validation workflow, not an exhaustive accessibility/security certification or automatic form-fixing tool.

## Compatibility and permissions

Markdown-reading agent; optional authorized source/browser tools depending on audit mode. Supplied-text analysis requires no account, network or runtime. Reading bundled/supplied files is expected. A saved audit requires an authorized destination; real form submissions, external messages/payments, implementation and deployment are not automatically authorized. No secrets or production personal data are bundled.
