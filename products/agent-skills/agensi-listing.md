## Title

Privacy-Aware Session Analysis

## Short description

Turn sanitized replay notes and funnel data into evidence-linked UX findings, prioritized fixes, and measurable validation plans.

## Description

Find the friction in onboarding, checkout, imports and other product workflows without turning a handful of recordings into unsupported conclusions.

This skill guides your AI agent through scoping the decision, minimizing data exposure, reconstructing the flow, checking funnel denominators, separating observed symptoms from possible causes, and proposing the smallest useful next action.

You receive an evidence-linked report with sample limitations, confidence levels, alternative explanations, ranked actions and a validation plan. The package includes a reusable report template, an evidence/counting reference and a fully fictional worked example.

Works from sanitized text notes and aggregate counts. For raw video or live analytics, your agent needs its own compatible viewing tools or authorized connector. No analytics subscription, API key, tracking installation or executable scripts are bundled. English instructions; reports can follow your language.

Designed for product managers, UX researchers, SaaS founders and developers. This is an analysis workflow, not a session recorder, legal-compliance certification or conversion guarantee.
