# Repository Feature Map

Version 1.0.0. Find the contracts, services, adapters, state owners and tests that already implement a capability before proposing new code. Includes a feature-brief template, compact index-row template, discovery method and fictional worked example.

Example request: "Map the existing shipment export flow from these source snippets. Identify the owner, invariants, reuse opportunities and acceptance gaps. Propose documentation corrections without editing."

Requires an agent capable of reading Markdown. Actual repository inspection requires authorized file/search tools in the host agent. Supplied source snippets also work, with provisional conclusions. No vendor, API key, executable script or external service is bundled. English instructions; output follows the user's language. Tested with Codex fictional scenarios only; other agents and arbitrary repositories are not independently verified.
