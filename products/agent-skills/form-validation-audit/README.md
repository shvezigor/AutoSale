# Form Validation Audit

Version 1.0.0. A focused agent workflow for reviewing user-editable web form validation and recovery. Includes an audit-method reference, audit-report template, acceptance matrix and fictional before/after example.

Example request: "Audit this sanitized form markup and observed invalid-submit behavior. Separate confirmed defects from unknown keyboard/runtime behavior, preserve native validation where appropriate, and propose the smallest fix with meaningful acceptance checks. Do not submit or edit anything."

Requires an agent capable of reading Markdown and supplied evidence. Actual source/browser/assistive testing needs compatible host tools, an authorized environment and appropriate fictional/test-account data. No browser, screen reader, framework, executable script, API key or test runner is bundled. English instructions; reports follow the user's language. It does not automatically fix or submit forms, redesign UI or certify accessibility, security or legal compliance.
