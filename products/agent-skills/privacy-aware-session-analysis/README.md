# Privacy-Aware Session Analysis

Version 1.0.0. A vendor-neutral instruction skill for turning sanitized session evidence and funnel data into prioritized product decisions.

Provide the flow, decision and authorized evidence to your agent. Example request:

> Analyze these sanitized onboarding replay notes and aggregate funnel counts. Separate observations from hypotheses, explain counting limits, and propose the smallest fix with a validation plan.

The package includes SKILL.md, a report template, a counting-method reference, and a fully fictional worked example. It needs an AI agent capable of reading Markdown. Live recordings, browser access, analytics connectors and video interpretation depend on the host agent and are not bundled or required for text evidence. No API key, tracking installation, executable script or external service is included.

This skill does not collect recordings, guarantee legal compliance, establish causality from replay alone, or promise a conversion lift. Use sanitized evidence and an authorized analysis environment. Reports follow the user's language; source instructions are English.
