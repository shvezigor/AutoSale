# Marketplace skill icons v1

Four marketplace card/logo assets generated with the built-in `image_gen` tool on 2026-10-26. Each is an original square PNG, 1254 × 1254 pixels, opaque navy background, under 5 MiB. They are visually reviewed for a shared ceramic/ivory style, distinct accent colors, clear symbols and absence of text or watermarks. These are listing images, not diagrams or certifications of safety.

| Skill | Icon | Accent / symbol |
|---|---|---|
| Privacy-Aware Session Analysis | [PNG](privacy-aware-session-analysis.png) | Emerald shield inside an eye |
| Repository Feature Map | [PNG](repository-feature-map.png) | Blue central cube and connected ivory cubes |
| Evidence-Led Product Planning | [PNG](evidence-led-product-planning.png) | Amber check on stacked planning cards |
| Docker Compose Release Planner | [PNG](docker-compose-release-planner.png) | Violet checked shield and server stack |

Full prompts and generator mode are recorded in [prompts.json](prompts.json); dimensions, byte sizes and SHA256 hashes are in [manifest.json](manifest.json). Original generated pixels are preserved without resizing or cropping. The generator returned 1254px assets rather than the 1024px requested in the prompts; they meet the square-image/minimum-resolution check. A 512px thumbnail rendering has not been separately exported or verified on Agensi.

PNG decoding, square dimensions, minimum 512px resolution, under-5-MiB sizes and a four-file ZIP round-trip were checked. The delivery archive is `sales-aito-skill-icons-v1.zip` in the owner's Downloads folder, outside Git. It contains only these four PNGs.

The matching PNGs were uploaded through each listing's Skill logo field on 2026-10-26 after owner approval; stored remote previews were verified by reopening all four edit forms. See the [submission record](../../agensi-submissions.md). They remain outside the Markdown-only skill distribution ZIPs; those packages and their hashes are unchanged. All four listings are pending review rather than live.
