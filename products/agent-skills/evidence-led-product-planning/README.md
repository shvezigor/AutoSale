# Evidence-Led Product Planning

Version 1.0.0. Turn a feature request into a focused product decision, small PRD or validation plan. Includes a decision-brief template, PRD template, evidence/metric method and fictional worked example.

Example request: "Two sales calls request automatic imports. We have a reviewed CSV import already. Should we build four provider integrations? Separate evidence from assumptions and propose the smallest useful next step without implementing."

Requires an agent capable of reading Markdown and supplied product context. Optional repository or research tools depend on the host agent and task. No customer data, connector, API key, executable script or analytics collection is bundled. English instructions; output follows the user's language. Tested with Codex fictional scenarios only. It does not establish demand, certify compliance or guarantee business results.
