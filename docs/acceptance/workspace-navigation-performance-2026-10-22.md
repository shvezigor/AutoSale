The follow-up adds safe web-to-API timing/error diagnostics. The next observed slow incident can now be split into the web-to-API hop and API request duration; a slow browser navigation with neither event still requires separate Next/edge/client investigation. This is instrumentation, **not a claimed speed improvement or a resolution of the earlier unidentified 5xx**.
